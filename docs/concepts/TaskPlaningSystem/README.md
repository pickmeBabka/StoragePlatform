# Глобальная централизованная система планирования задач и ресурсов (СПЗР)

## Обзор
СПЗР — это централизованная система, предназначенная для распределения вычислительных ресурсов между задачами, выполняющимися на множестве распределенных платформ. Она берет на себя задачи формирования оптимального расписания, профилирования нагрузки и учета мягких ограничений (например, сетевого трафика и стоимости передачи данных).
